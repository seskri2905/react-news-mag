# NEWS MAGAZINE WEBSITE 📰🗞🌐 - REACT + BOOTSTRAP ✨

## INTRODUCTION ⭐

• The Project is about the collection of all reputed news sources in a single page
• API is fetched through the `https://newsapi.org/` API

---

## HOW TO GET API KEY ❓

• Create an account / Login (if created)
• Click on `Get API Key`
• Copy the API Key and make sure to store the key in .env and mention in .gitignore to avoid deployment
